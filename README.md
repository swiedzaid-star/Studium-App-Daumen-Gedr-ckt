# Studium-App

Private, nicht kommerzielle Lern-App für das Wintersemester 26/27 (Wirtschaftsingenieurwesen, Fachrichtung Bauingenieurwesen). Kein offizielles Angebot einer Hochschule.

- `index.html`, `app.js`, `app.css`: die App (läuft komplett im Browser, Fortschritt bleibt im Browser gespeichert)
- `data.js`: Inhalte (eigene Zusammenfassungen, eigene Aufgaben, Termine)
- `vendor/`: lokal eingebundene Schriften (SIL Open Font License) und MathJax (Apache License 2.0)

Online über GitHub Pages. Datenschutzhinweise in der App unter „Mein Studiengang“.
